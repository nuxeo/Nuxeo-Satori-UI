# Users and groups page

The users and groups page is the administration screen for accounts. It searches users and groups
together, lists the recently created ones, and creates, edits and deletes either kind. It opens the
user and group dialogs for each action, and asks before a deletion.

## Key features

- **One search, two lists.** Search matches users and groups; a search that matches only one kind
  opens that kind's tab.
- **Recently created.** The table above the lists shows the latest accounts, five to a page.
- **Outcomes stay visible.** Each action reports on a status line that stays until the next action,
  so a refusal is still on screen after its dialog closes. A refusal is an alert.
- **It does not navigate.** Choosing a user or a group calls `userChosen` or `groupChosen` with its id; the host routes to the details page.

## Accessibility

The search is a form with a labelled field and a named submit button. Each row action is named with
the user or group it acts on. Refusals use `role="alert"`; results use `role="status"`.

## Usage

```html
<nxs-admin-users-groups-page [userChosen]="openUser" [groupChosen]="openGroup" />
```

The page's words are translated under `satori-components.admin-users-groups-page.*`. It writes through
`UserService`, and Nuxeo checks each permission on the request.
