# Avatar

An avatar shows a person's initials in a coloured circle. Use it beside a person's name — in a list
of users, on a comment or task, in a header — or on its own where there is no room for the name.

## Key features

- **Six sizes**, from 24 to 128 pixels, each with a matching type size.
- **Eight colours**: `purple`, `blue`, `pink`, `teal`, `yellow`, `green`, `red` and `orange`.
- **Named or decorative.** With a `label` it is announced as an image with that name. Without one —
  or with one that is only spaces or invisible characters — it is hidden from assistive technology,
  for use next to the visible name.
- **Each name is its colour, in any theme.** A `teal` avatar is teal under a blue, rose or cyan
  theme, light or dark: each name has its own hue, blended with your theme's surface for the circle
  and with its text colour for the initials, at 4.5:1 or more. Set `--nxs-avatar-<colour>-background`
  and `--nxs-avatar-<colour>-foreground` to give a colour your own hue.
- **One initial at 24 pixels**, where two do not fit, as Satori's avatar does.
- **Replaceable by ID.** It is registered as `nxs.primitives.avatar`, so Satori's avatar or your own
  can take its place without changing the screens that show it.

## Usage

Import it from the components entry point. Used directly, it needs no providers.

<Source
  language="typescript"
  dark
  code={`import { NxsAvatarComponent } from '@nuxeo-satori/platform/components';`}
/>

<Source
  language="html"
  dark
  code={`<nxs-avatar initials="NK" color="teal" label="Narasimha Koppula" />`}
/>

Only `initials` is required. `color` defaults to `blue`, `size` to `36`, and `label` to blank. Pass
the label already translated or, for a person's name, as it is.

### By registered ID

`provideNxsComponents()` registers the avatar as `nxs.primitives.avatar`, exported as
`NXS_PRIMITIVE_IDS.avatar`. Render the ID where you want the avatar to be replaceable, and pass the
same inputs:

export const byRegisteredIdHtml = `<lib-extension-outlet
  [componentId]="avatarId"
  [componentInputs]="{ initials: 'NK', color: 'teal', label: 'Narasimha Koppula' }"
/>`;

## Accessibility

- **Name.** With a `label`, the avatar has the `img` role and the label is its accessible name. Use
  the person's full name, not their initials.
- **Decorative.** With a blank `label`, the whole avatar is hidden from assistive technology. Use it
  this way only next to the visible name. A label of only spaces or invisible characters counts as blank, and the spaces
  around a name are not announced.
- **Initials.** The initials are never announced on their own; the label is.
- **Keyboard.** The avatar is not interactive and takes no focus. To make it open a profile, wrap it
  in a link or button and give that the accessible name.
- **Contrast.** Each colour pairs a theme container colour with its matching text colour, which
  Material designs to contrast. Teal's pair holds 4.5:1 on Material's light and dark themes. If you
  set your own colours, check the contrast of the pair.

## Satori and the built-in avatar

The same ID, `nxs.primitives.avatar`, renders **Satori's avatar** when
`@nuxeo-satori/platform/components-satori` is installed and `provideNxsSatoriComponents()` is listed
after `provideNxsComponents()`. Otherwise it renders the **built-in avatar** shown on this page.
Both take the same four inputs, so the screens that render the ID do not change.

What looks different:

- Satori's avatar has a thin border around the circle. The built-in avatar has none.
- Both give each name its own hue. Satori's shades come from Satori's theme; the built-in ones are
  blended with your Material theme's surface and text, so they are a little greyer.

Satori's own avatar can also show a photo, a status indicator or no border. The registered ID does
not have inputs for those, so neither version offers them through the ID.

This Storybook is built without access to GitHub Packages, so every example here shows the built-in
avatar. Satori's avatar is shown in Satori's documentation.
