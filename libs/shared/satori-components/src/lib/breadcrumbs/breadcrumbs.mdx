# Breadcrumbs

Breadcrumbs show where the current page sits in a hierarchy, such as a document's folders, and let
the user go back up it in one click. Use them at the top of a page whose location matters, under
the page title.

## Key features

- **Three kinds of item.** An item with `routerLink` navigates inside the application, an item with
  `href` is a plain link, and an item with neither is text.
- **Current page.** When the last item is text, it is marked as the current page for assistive
  technology.
- **Navigation landmark.** The trail is a named `nav` region, so screen reader users can jump to
  it.
- **Wraps when long.** A trail wider than its container wraps onto further lines.
- **Replaceable by ID.** It is registered as `nxs.primitives.breadcrumbs`, so Satori's breadcrumbs
  or your own can take its place.

## Usage

<Source
  language="typescript"
  dark
  code={`import { NxsBreadcrumbsComponent, type NxsBreadcrumbItem } from '@nuxeo-satori/platform/components';

protected readonly trail: NxsBreadcrumbItem[] = [
{ label: 'Domain', routerLink: ['/browse'], queryParams: { path: '/default-domain' } },
{ label: 'Workspaces', routerLink: ['/browse'], queryParams: { path: '/default-domain/workspaces' } },
{ label: 'Contracts' },
];`}
/>

<Source
  language="html"
  dark
  code={`<nxs-breadcrumbs [items]="trail" [label]="'acme.breadcrumbs' | translate" />`}
/>

Only `items` is required. An item with `routerLink` needs the Angular router, which an application
already provides. Pass labels already translated.

### By registered ID

`provideNxsComponents()` registers the breadcrumbs as `nxs.primitives.breadcrumbs`, exported as
`NXS_PRIMITIVE_IDS.breadcrumbs`. Render the ID with the same inputs:

<Source
  language="html"
  dark
  code={`<lib-extension-outlet
  [componentId]="breadcrumbsId"
  [componentInputs]="{ items: trail, label: 'Breadcrumbs' }"
/>`}
/>

## Accessibility

- **Landmark.** The trail is a `nav` element named by `label`. Give it a short name such as
  "Breadcrumbs", translated. Without a label the landmark has no name.
- **Structure.** The items are an ordered list, so a screen reader announces how many there are and
  where each one sits.
- **Current page.** A last item without a link has `aria-current="page"`.
- **Separators.** The chevrons between items are hidden from assistive technology.
- **Keyboard.** Every link is a native link: **Tab** reaches it and **Enter** follows it. Text items
  are not focusable.

## Satori and the built-in breadcrumbs

The same ID, `nxs.primitives.breadcrumbs`, renders **Satori's breadcrumbs** when
`@nuxeo-satori/platform/components-satori` is installed and `provideNxsSatoriComponents()` is listed
after `provideNxsComponents()`. Otherwise it renders the **built-in breadcrumbs** shown on this page.
Both take the same inputs.

What looks and behaves differently:

- **Long trails.** Satori's breadcrumbs collapse the middle of a trail that does not fit into a menu.
  The built-in breadcrumbs wrap onto further lines instead.
- **Landmark name.** Satori's breadcrumbs name the landmark from Satori's own translations and do not
  read `label`. The built-in breadcrumbs use `label`.
- **Styling.** Satori's breadcrumbs use Satori's type, colours and chevron icon. The built-in
  breadcrumbs use your Material theme.

Satori's breadcrumbs need `provideSatori()` for their icon and Satori's translations loaded in
ngx-translate; without the translations the landmark's name shows as a raw key.

This Storybook is built without access to GitHub Packages, so every example here shows the built-in
breadcrumbs. Satori's breadcrumbs are shown in Satori's documentation.
