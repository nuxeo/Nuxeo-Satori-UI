# Change password dialog

The change-password dialog sets a user's password. An administrator opens it from a user's details
page. It does not save anything itself: it closes with the new password, and the caller sends it to
the server.

## Key features

- **Two fields that must agree.** Set password stays off until both fields have text and match, and a blank
  password, whitespace included, is refused. The password is trimmed before it is returned.
- **The account is named.** The dialog shows the username it is changing, so the administrator can
  see whose password it is.
- **Nothing is decided here.** The server checks whether the administrator may change the password.

## Accessibility

The fields are labelled "New password" and "Confirm password", and the first field takes focus when the
dialog opens. A mismatch is announced with `role="alert"` under the fields, and Set password is disabled
while it stands, so a screen reader user hears why the button will not work.

## Usage

export const usageTs = `import {
  NxsChangePasswordDialogComponent,
  type NxsChangePasswordDialogData,
} from '@nuxeo/satori-platform/components';

this.dialog
  .open<NxsChangePasswordDialogComponent, NxsChangePasswordDialogData, string>(
    NxsChangePasswordDialogComponent,
    { data: { username: user.id } },
  )
  .afterClosed()
  .subscribe((password) => {
    if (password) this.setPassword(user.id, password);
  });`;

<Source language="typescript" dark code={usageTs} />

`username` is required. `afterClosed()` gives the trimmed password, or nothing when the user cancels.
The dialog's words are translated with ngx-translate under `satori-components.change-password-dialog.*`.
It has no registered ID: open it with `MatDialog`.
