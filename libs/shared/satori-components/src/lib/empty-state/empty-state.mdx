# Empty state

The empty state is the "nothing here" message for a list, panel or set of results: a heading, an
optional second line, an optional icon, and any buttons you place inside it. Use it instead of an
empty table or a blank area, so the user knows the place is empty on purpose and what to do next.

## Key features

- **A heading and a next step.** `heading` says what is empty; `message` usually says what to do
  about it.
- **Your actions.** Buttons such as "Create folder" or "Clear filters" are placed inside the
  component as content, so they and what they do stay yours.
- **A real heading.** The heading is a native `<h1>` to `<h6>`, at the level you choose, so heading
  navigation stays in order.
- **Announced when it appears.** It is a status region.

## Usage

<Source
  language="typescript"
  dark
  code={`import { NxsEmptyStateComponent } from '@nuxeo-satori/platform/components';`}
/>

<Source
  language="html"
  dark
  code={`<nxs-empty-state
  [heading]="'acme.results.empty' | translate"
  [message]="'acme.results.empty-hint' | translate"
  icon="search_off"
>
  <button mat-button type="button" (click)="clearFilters()">
    {{ 'acme.results.clear-filters' | translate }}
  </button>
</nxs-empty-state>`}
/>

Only `heading` is required, already translated. The library ships no translations for the text you
give it. Used directly, the empty state needs no providers.

## Accessibility

- **Announced.** The component has the `status` role, so assistive technology reads it when it
  appears — after a search returns nothing, for example — without moving focus.
- **Heading.** The heading is a native heading element at `headingLevel`. Choose the level that fits
  the page outline.
- **Icon.** The icon is decorative and hidden from assistive technology. The heading says what it
  means.
- **Keyboard.** The component itself takes no focus. Buttons you place inside it are reached with
  **Tab** as usual.
