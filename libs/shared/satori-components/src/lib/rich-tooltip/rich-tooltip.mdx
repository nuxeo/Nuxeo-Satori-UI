# Rich tooltip

A rich tooltip is a small icon button that opens a short explanation with a title. Use it beside a
field, a column header or a setting whose meaning needs a sentence or two, when that text would
clutter the page if it were always shown. For one word or a short phrase, a plain tooltip is enough.

## Key features

- **A title and a sentence or two.** `heading` is the title and `content` the explanation, both
  plain text.
- **Opens on demand.** The button opens the panel; **Escape** or moving focus away closes it. The
  panel does not cover the page or trap focus.
- **Announced when it opens.** The panel opens inside a live region, so a screen reader reads it
  without the user moving to it.
- **Stays on screen.** The panel is never wider than the window, and moves sideways to stay inside
  it when the button sits near either edge, in left-to-right and right-to-left layouts alike.
- **Any icon.** `info` by default; any Material Icons ligature through `icon`.
- **Replaceable by ID.** It is registered as `nxs.primitives.richTooltip`, so Satori's rich tooltip
  or your own can take its place.

## Usage

<Source
  language="typescript"
  dark
  code={`import { NxsRichTooltipComponent } from '@nuxeo-satori/platform/components';`}
/>

<Source
  language="html"
  dark
  code={`<nxs-rich-tooltip
  [heading]="'acme.versioning.title' | translate"
  [content]="'acme.versioning.help' | translate"
  [triggerLabel]="'acme.versioning.about' | translate"
/>`}
/>

`heading`, `content` and `triggerLabel` are required, already translated. Used directly, the rich
tooltip needs no providers.

### By registered ID

`provideNxsComponents()` registers the rich tooltip as `nxs.primitives.richTooltip`, exported as
`NXS_PRIMITIVE_IDS.richTooltip`:

<Source
  language="html"
  dark
  code={`<lib-extension-outlet
  [componentId]="tooltipId"
  [componentInputs]="{ heading: 'Versioning', content: 'A new version is created each time you check in.', triggerLabel: 'About versioning' }"
/>`}
/>

## Accessibility

- **Name.** The button shows only an icon, so `triggerLabel` is its accessible name. Say what the
  explanation is about, such as "About versioning", not "Info".
- **State.** The button reports whether the panel is open (`aria-expanded`) and which element it
  controls (`aria-controls`).
- **Keyboard.** **Tab** reaches the button. **Enter** or **Space** opens and closes the panel.
  **Escape** closes it and keeps focus on the button. Moving focus out of the component closes it.
- **Announcement.** The panel opens inside a `status` live region, so a screen reader reads the title
  and text while focus stays on the button. It is not a dialog: a dialog takes focus when it opens.
- **Content.** Keep the text short and plain. The panel holds no links or buttons.

## Satori and the built-in rich tooltip

The same ID, `nxs.primitives.richTooltip`, renders **Satori's rich tooltip** when
`@nuxeo-satori/platform/components-satori` is installed and `provideNxsSatoriComponents()` is listed
after `provideNxsComponents()`. Otherwise it renders the **built-in rich tooltip** shown on this page.
Both take the same four inputs.

What behaves differently:

- **How it opens.** Satori's rich tooltip opens when the pointer rests on the button or the button
  receives keyboard focus, and closes when they leave. The built-in one opens when the button is
  activated — a click, **Enter** or **Space** — and stays open until **Escape** or focus moves away.
- **Styling.** Satori's panel uses Satori's surface, type and close hint. The built-in panel uses your
  Material theme.

Satori's rich tooltip needs `provideSatori()` and Satori's translations loaded in ngx-translate;
without the translations its close hint shows as a raw key.

This Storybook is built without access to GitHub Packages, so every example here shows the built-in
rich tooltip. Satori's rich tooltip is shown in Satori's documentation.
