# Tag

A tag is a short, static label in a colour. Use it to show a category at a glance — a document type,
a classification, a state that does not change while the user looks at it. A tag is not a button and
not a filter chip: it does nothing when clicked.

## Key features

- **Nine colours**: `gray`, the default, plus the eight avatar colours.
- **Never cut short.** A label longer than the space it has wraps onto a further line inside the
  tag, as Web UI's tags do, rather than being cut off or spilling out of its box.
- **Each name is its colour, in any theme.** The eight hues are the avatar's, blended with your theme's
  surface and text at 4.5:1 or more; `gray` is your theme's neutral container. Set
  `--nxs-tag-<colour>-background` and `--nxs-tag-<colour>-foreground` to give a colour your own hue.
- **Replaceable by ID.** It is registered as `nxs.primitives.tag`, so Satori's tag or your own can
  take its place.

## Usage

<Source
  language="typescript"
  dark

<Source
  language="html"
  dark
  code={`<nxs-tag [label]="'acme.type.invoice' | translate" color="purple" />`}
/>

Only `label` is required, already translated. `color` defaults to `gray`. Used directly, the tag
needs no providers.

### By registered ID

`provideNxsComponents()` registers the tag as `nxs.primitives.tag`, exported as
`NXS_PRIMITIVE_IDS.tag`:

  [componentId]="tagId"
  [componentInputs]="{ label: 'Invoice', color: 'purple' }"

## Accessibility

- **Name.** The tag is plain text: assistive technology reads the label. It has no role of its own.
- **Colour.** A colour is never announced. Do not rely on it to carry meaning.
- **Keyboard.** The tag is not interactive and takes no focus.
- **Contrast.** Each colour's text holds 4.5:1 on its background in Material's light and dark themes.
  If you set your own colours, check the contrast of the pair.

## Satori and the built-in tag

The same ID, `nxs.primitives.tag`, renders **Satori's category tag** when
`@nuxeo/satori-platform/components-satori` is installed and `provideNxsSatoriComponents()` is listed
after `provideNxsComponents()`. Otherwise it renders the **built-in tag** shown on this page. Both
take the same inputs and the same nine colour names.

What looks different: both give each name its own hue, Satori's in Satori's shades and type, the
built-in one blended with your Material theme's surface and text. A label longer than the space
wraps in the built-in tag; Satori's stays on one line and spills out of a narrow box.

This Storybook is built without access to GitHub Packages, so every example here shows the built-in
tag. Satori's tag is shown in Satori's documentation.
