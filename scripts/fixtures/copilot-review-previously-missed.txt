<summary><picture><source media="(prefers-color-scheme: dark)" srcset="https://github.githubassets.com/static/images/icons/copilot-code-review/medium-v2-dark.svg"><source media="(prefers-color-scheme: light)" srcset="https://github.githubassets.com/static/images/icons/copilot-code-review/medium-v2-light.svg"><img src="https://github.githubassets.com/static/images/icons/copilot-code-review/medium-v2-light.png" alt="Medium severity" width="62" height="18" align="texttop"></picture> Missing --root causes exit 1 instead of documented exit 2</summary>

`scripts/​beta-harness/​dependency-tree.mjs:131`

The documented exit-code contract is not honored for `--root`: `realpathSync` runs before gap handling, so a missing or inaccessible root throws a stack trace and exits 1 (the code reserved for findings) rather than exit 2 for an inspection failure. Catch root resolution errors and terminate with the same CANNOT INSPECT/exit-2 behavior as other unreadable locations.
</details>

<details>
<summary><picture><source media="(prefers-color-scheme: dark)" srcset="https://github.githubassets.com/static/images/icons/copilot-code-review/medium-v2-dark.svg"><source media="(prefers-color-scheme: light)" srcset="https://github.githubassets.com/static/images/icons/copilot-code-review/medium-v2-light.svg"><img src="https://github.githubassets.com/static/images/icons/copilot-code-review/medium-v2-light.png" alt="Medium severity" width="62" height="18" align="texttop"></picture> readJson accepts null or arrays without recording an inspection gap</summary>

`scripts/​beta-harness/​dependency-tree.mjs:645`

`JSON.parse()` may succeed with `null`, but `readJson` then returns `null` without recording a gap. Both the lockfile and manifest callers silently skip that file, so an invalid-but-readable `package-lock.json`/`package.json` can produce a clean verdict instead of the promised exit 2. Validate that the parsed value is a non-array object and add a gap otherwise; add a negative control for this valid-JSON/wrong-shape case.
</details>
